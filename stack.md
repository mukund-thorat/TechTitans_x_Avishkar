# 🎨 UI / UX Principles

- Keep UI **minimal and clean**
- Avoid unnecessary shadows
- Prefer:
  - borders (`border`, `border-muted`)
  - subtle backgrounds (`bg-muted`)
  - secondary text color (`text-foreground-muted`)
- Focus on readability over decoration
